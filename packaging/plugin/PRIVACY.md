# Privacy

This Skill runs locally in the user's Agent workspace.

- It does not include telemetry, analytics, advertising, or remote logging.
- Course source files, `live.json`, `memory.json`, previews, and deliverables remain in
  the selected workspace.
- The model provider selected by the host Agent may process content required to complete
  the user's request. Follow that provider's data policy.
- Browser validation uses a local headless browser and loopback debugging port.
- No credentials are required by this Skill. Optional billing integrations are supplied
  by the host and are not bundled here.

# Courseware Workflow Plugin Template

This directory contains only the plugin-specific files. The release builder copies
the canonical Skill from `skill/courseware-workflow/` into
`skills/courseware-workflow/` while creating the plugin archive.

Do not add a second editable Skill copy here.

The generated plugin supports Codex marketplace and provides the native Skill
entrypoint for DSH, DeepSeek Harness, Claude-style, and generic Markdown Agent
hosts.
